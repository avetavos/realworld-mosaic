deploy แต่ละ slice — UI และ BFF — แยกกัน, version remote, และพิสูจน์ว่าคุณ ship การเปลี่ยนแปลงของทีมเดียวได้โดยไม่ต้อง rebuild ตัวอื่น

บทเรียนของ module นี้กำลังจะมา — ติดตามที่แถบด้านข้างเมื่อมันทยอยลง
