ประสาน routing ข้าม app อิสระ: shell เป็นเจ้าของ top-level route, แต่ละ remote เป็นเจ้าของ sub-route ของมัน, และ deep link resolve เข้า slice ที่ถูกต้อง

บทเรียนของ module นี้กำลังจะมา — ติดตามที่แถบด้านข้างเมื่อมันทยอยลง
