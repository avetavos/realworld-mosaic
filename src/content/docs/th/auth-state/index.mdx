share auth/session เดียวข้ามทุก remote ผ่าน singleton ที่ shell เป็นเจ้าของ เพื่อให้ทุก MFE รู้ว่าใคร sign in อยู่โดยไม่ต้องพึ่งกัน

บทเรียนของ module นี้กำลังจะมา — ติดตามที่แถบด้านข้างเมื่อมันทยอยลง
