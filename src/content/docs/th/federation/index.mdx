เรียนรู้ Module Federation 2.0 แบบลงมือ: expose remote, consume มันตอน runtime จาก remoteEntry, และ share singleton เพื่อให้ React โหลดครั้งเดียว

บทเรียนของ module นี้กำลังจะมา — ติดตามที่แถบด้านข้างเมื่อมันทยอยลง
