ให้ remote สื่อสารกันผ่าน event bus ที่ decoupled — "add to cart" จาก catalog อัปเดต cart โดยไม่มี remote ไหน import อีกตัว

บทเรียนของ module นี้กำลังจะมา — ติดตามที่แถบด้านข้างเมื่อมันทยอยลง
